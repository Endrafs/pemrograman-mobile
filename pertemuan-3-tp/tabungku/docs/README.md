# Tangkapan Layar

Folder ini berisi dua tangkapan layar aplikasi pada ukuran layar yang berbeda:

1. `screenshot_phone.png` — tampilan ponsel dalam posisi potret.
2. `screenshot_tablet.png` — tampilan tablet.

## Cara Mengambil

1. Jalankan aplikasi:

   ```bash
   flutter run
   ```

2. Pilih emulator ponsel, lalu ambil tangkapan layar halaman Ringkasan Tabungan. Simpan sebagai `docs/screenshot_phone.png`.
3. Jalankan ulang pada emulator tablet (atau ubah ukuran perangkat), lalu ambil tangkapan layar. Simpan sebagai `docs/screenshot_tablet.png`.

Contoh ukuran yang bisa dipakai:

- Ponsel: 390 × 844 (Pixel 7)
- Tablet: 1024 × 1366 (iPad Pro 12.9" potret) atau 800 × 1280
